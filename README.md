# FairShare-AI — симулятор городских решений для Петропавловска

**Qyzyljar AI / Smart Region** — название региональной версии в интерфейсе. Проект развивает учебный симулятор SteppeX и готовится к AI BATTLE: Smart Region Edition. В этом репозитории находятся все компоненты приложения: сайт, backend, Python-симулятор, тесты и документация.

У города много задач, а бюджет ограничен. FairShare-AI помогает исследовать, как набор инициатив меняет качество городской среды, положение наиболее слабой зоны и оставшийся резерв. Пользователь выбирает пять мер, получает воспроизводимый расчёт, сравнивает альтернативы и, при подключённом API, обсуждает риски и компромиссы с ИИ-советником.

**Это учебный прототип.** Не официальное задание мероприятия и не цифровой двойник города. Реальные источники подтверждают темы, но все баллы, веса, сроки, эффекты и бюджет условные. [Происхождение данных и ограничения](docs/data-sources.md).

## Что умеет приложение

- 15 инициатив по транспорту, социальной инфраструктуре, благоустройству, ЖКХ и безопасности.
- Пять учебных зон Петропавловска; это не официальное административное деление города.
- Бюджет 100 условных единиц, горизонт восемь кварталов, ровно пять мер и не более двух мер одного направления.
- Четыре редактируемых стартовых сценария: «Социальный баланс», «Надёжное ЖКХ», «Город без барьеров», «Устойчивая среда».
- Сравнение вариантов по трём целям: общий результат, поддержка слабой зоны и бюджетный резерв.
- ИИ-анализ рисков и диалог на основе результатов инструментов, а не придуманных моделью чисел.
- Экспорт сценария в JSON и доступные в интерфейсе источники и ограничения.

Сайт написан на React и TypeScript, backend — на Node.js / Express. Числа независимо пересчитываются на Python и сверяются перед выдачей результата. Папка `ml/` содержит **детерминированный симулятор, не обученную ML-модель**. Поиск альтернатив ограничен заменой или переносом одной меры и не гарантирует глобальный оптимум.

## Структура репозитория

```text
FairShare-AI/
├── frontend/                 # Интерфейс React + TypeScript, Vite
│   ├── src/                  # Сценарии, сравнение, диалог и экспорт
│   └── test/                 # Проверки подключения
├── backend/                  # HTTP API, расчётный движок и ИИ-агент
│   ├── src/                  # Сервер, инструменты агента, сессии
│   ├── data/city.json        # Синтетический каталог и сценарии
│   ├── test/                 # Тесты API, расчётов и агента
│   ├── .env.demo             # Публичные настройки демо без ключа
│   └── .env.example          # Шаблон настроек с пояснениями
├── ml/                       # Независимый Python-пересчёт и тесты
├── scripts/                  # Общий запуск и smoke-проверка
├── docs/                     # Источники, ограничения и план защиты
└── package.json              # Общие команды проекта
```

Настоящий `backend/.env`, зависимости `node_modules/`, сборка `dist/` и кеши не публикуются. Приложение не требует Docker, базы данных или отдельного Python-сервера; внешние Python-библиотеки устанавливать не нужно.

## Быстрый запуск на Windows

### 1. Установите инструменты и скачайте проект

Нужны **Node.js 22.9+**, **Python 3.10+** и, для клонирования, Git. При установке Python включите добавление в PATH, затем откройте новый PowerShell. Python определяется автоматически (`python`, `python3`, `py -3`).

```powershell
git clone https://github.com/mikva064/FairShare-AI.git
cd FairShare-AI
node --version
py -3 --version
```

Если Python установлен без команды `py`, проверьте `python --version`. Без Git можно нажать **Code → Download ZIP** на странице репозитория, распаковать архив и открыть PowerShell в распакованной папке. Корень проекта — папка, где одновременно находятся `package.json`, `backend/` и `frontend/`.

### 2. Подготовьте бесплатное демо и зависимости

```powershell
if (-not (Test-Path -LiteralPath "backend/.env")) {
    Copy-Item -LiteralPath "backend/.env.demo" -Destination "backend/.env"
}
npm.cmd --prefix backend ci
npm.cmd --prefix frontend ci
```

Команда копирования не перезаписывает уже существующий `.env`. Выполняйте команды по очереди; при ошибке установки не переходите к запуску. Интернет нужен для скачивания зависимостей. Отдельный `npm install` в корне не нужен.

### 3. Запустите сайт

```powershell
npm.cmd run dev
```

После сообщения «Qyzyljar AI готов» откройте [сайт на своём компьютере](http://127.0.0.1:5180/). Команда проверяет Python, собирает frontend и запускает оба сервера:

- frontend: `http://127.0.0.1:5180/`;
- backend: `http://127.0.0.1:3010/`;
- проверка состояния: [GET /api/health](http://127.0.0.1:3010/api/health).

Держите терминал открытым; **Ctrl+C** останавливает приложение. Для следующих запусков достаточно открыть корень проекта и выполнить `npm.cmd run dev`. После изменений кода остановите и запустите приложение заново: эта команда использует собранный сайт, автоматического HMR нет.

При пустом ключе расчёты, Python-проверка, сравнение и экспорт работают. Сообщение «ИИ не настроен» и `aiConfigured: false` в проверке состояния — нормальное поведение бесплатного демо, не ошибка. Ответы настоящего ИИ без ключа не имитируются.

### macOS / Linux

С теми же версиями Node.js и Python:

```bash
git clone https://github.com/mikva064/FairShare-AI.git
cd FairShare-AI
node --version
python3 --version
test -f backend/.env || cp backend/.env.demo backend/.env
npm --prefix backend ci

```

Если один из шагов завершился ошибкой, устраните её до следующего шага. Адрес сайта тот же: `http://127.0.0.1:5180/`.

## Демо для эксперта за две минуты

1. Выберите «Надёжное ЖКХ» или «Устойчивая среда». Это готовые, но редактируемые наборы пяти мер.
2. Нажмите «Рассчитать сценарий». Появятся индекс, бюджет и изменения по учебным зонам.
3. Сравните три альтернативы: качество жизни, слабая зона и резерв. Примените одну из них.
4. Откройте «Источники, учебные зоны и ограничения модели». Покажите отличие официального контекста от учебных чисел.
5. Кнопка «Скачать сценарий JSON» сохраняет числовой сценарий для разбора без ключей и истории диалога. Если браузер не скачивает файл, скопируйте JSON из появившегося поля и сохраните в текстовый файл с расширением `.json`.
6. С настроенным ключом задайте: «Какие компромиссы есть у этого набора для Петропавловска? Как сохранить резерв, не ухудшая слабую зону?»

Базовый пример «Социальный баланс»: расходы 95, резерв 5, индекс 56.54307 (в интерфейсе 56.54). Эти значения унаследованы от учебного набора, не измерены в городе. Проверка Python — независимый пересчёт, не обучение нейросети.

## Настоящий ИИ — необязательно и платно

В комплекте только пустой ключ. Добавьте собственный `OPENAI_API_KEY` **только в локальный `backend/.env`**, оставьте `OPENAI_MODEL=gpt-5-mini`, затем перезапустите сервер. Ключ предыдущего проекта сюда не переносится. Не добавляйте его в frontend, шаблоны env или GitHub.

Если ключ уже задан в окружении терминала, он имеет приоритет над файлом. Для демо без ИИ очистите переменную только текущего PowerShell командой `Remove-Item Env:OPENAI_API_KEY -ErrorAction SilentlyContinue` и оставьте значение в `.env` пустым. В bash используйте `unset OPENAI_API_KEY`.

Обычные расчёты, Python и стратегии не вызывают API. Платный анализ запускается кнопкой с подтверждением; один ответ может включать до четырёх обращений модели и ожидание до 90 секунд. «Да, помоги» бесплатно уточняет цель; содержательный следующий ответ платный. Применение варианта бесплатно. Ошибки запроса тоже могут расходовать токены. Окончательная стоимость проверяется в кабинете провайдера.

ИИ использует проверенные инструменты, региональный контекст и ограниченную историю. Сессии живут в памяти до 30 минут бездействия, не переживают перезапуск, максимум шесть платных ответов. Обновление страницы и ручная смена набора сбрасывают диалог в интерфейсе. Живой API для этой региональной версии при создании не проверялся.

## Проверки и ошибки

```powershell
npm.cmd test
npm.cmd --prefix frontend run build
npm.cmd run smoke
```

Для `smoke` сервер должен быть запущен в другом терминале. Эти проверки не делают платных запросов. Отдельно: `py -3 -m unittest discover -s ml -p "test_*.py"` (на macOS/Linux `python3`).

- `ENOENT package.json`: откройте терминал в корне **этого** проекта.
- Python не найден: установите Python 3.10+ или задайте `PYTHON_BIN` в `.env`.
- Порт занят: остановите прошлую копию Qyzyljar AI. Старый SteppeX можно не закрывать.
- Backend недоступен: проверьте терминал и http://127.0.0.1:3010/api/health. Не открывайте `dist/index.html` напрямую.
- ИИ не настроен: это нормальное состояние бесплатного демо.
